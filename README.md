# 灵感工作台 · STORY WORKBENCH

写给故事创作者的高频共情选题工具：**不替你想故事，只帮你锁定「还没被写烂」的那个点。**

在线使用：<https://ayu0228.github.io/story-matrix/>

## 这是什么

一个纯静态网站，把「什么样的故事值得写」拆成一套可组合的配方体系：

- **26 个灵感方向**：共情故事（爱情、亲情、友情、金钱、公平、生死、成长……，按「和谁的事」分组）+ 行业热门类型（逆袭、复仇、甜宠、身份反差、重生改写、悬疑、职场、年代，来自短剧/网文平台高频题材）
- **145 个分类 → 490+ 个共情情境**（如「单相思」「被抢功劳」「被退婚」「怪谈规则」）
- **690+ 组人物关系**（如「互相拆台的搭档」「被退婚的赘婿与未婚妻一家」）
- **490+ 个故事场景**（如「凌晨四点的便利店」「退婚的酒席」）
- **10+ 个转折词**（背叛、和解、牺牲、亏欠……可自定义）

在「灵感组合」页点随机，多个维度自动碰撞成一条配方，**故事 / 音乐 / 短视频三种模式**各配专属元素（音乐=视角+金句方向，短视频=钩子类型，均参考行业实践）；看到顺眼的就点 **+** 收进配方篮，可调可存，一键送去「工作台」开写。

## 不是内容库，是生成器

和常见的「故事素材库」不同，这里的关键词不是成品剧情，而是**经过拆解的、可再组合的最小单元**。490 × 690 × 490 的理论组合空间里，绝大多数从未被写过——工具负责把碰撞结果推到你面前，取舍和落笔永远是你自己的事。

## 数据存在哪里

- 网站本身零后端、零数据库、零追踪，所有页面均为静态文件
- 你的自定义方向、分类、情境、关系、场景、配方，全部存放在**你自己的 GitHub 私有仓库**（通过网页右上角「存储」连接），网站只在你浏览器里运行，任何人（包括项目作者）都看不到你的数据
- 连接用的 fine-grained 令牌仅授权那一个私有仓库的读写，且默认关闭浏览器即失效

## 页面一览

| 页面 | 作用 |
|---|---|
| 首页 | 体系总览与数字；今日配方（故事/音乐/短视频）可一键送去工作台 |
| 灵感方向 | 方向 → 分类 → 情境 三层下钻，全体系可增删改（悬停卡片出现 ✎/✕，虚线卡新建） |
| 灵感组合 | 随机配方生成器（三种模式专属列）+ 配方篮，可命名存档，一键送去工作台 |
| 工作台 | 小说（分章+大纲+世界观+人物）、音乐（主题/结构/乐器/流派/氛围）、短视频（故事+分镜）三模块创作；项目可跨类型衍生创建 |
| 怎么用 | 方法论文档：从配方到开篇的五个动作 |

## 技术
