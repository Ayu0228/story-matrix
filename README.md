# 灵感矩阵 · STORY MATRIX

写给故事创作者的高频共情选题工具：**不替你想故事，只帮你锁定「还没被写烂」的那个点。**

在线使用：<https://ayu0228.github.io/story-matrix/>

## 这是什么

一个纯静态网站，把「什么样的故事值得写」拆成一套可组合的配方体系：

- **18 个灵感方向**（爱情、亲情、友情、金钱、公平、生死、成长……），按「和谁的事」分三组
- **105 个分类 → 371 个共情情境**（如「单相思」「被抢功劳」「目睹作弊」）
- **541 组人物关系**（如「互相拆台的搭档」「全职太太与丈夫」）
- **337 个故事场景**（如「凌晨四点的便利店」「末班地铁车厢」）
- **10 个转折词**（偏偏、没想到、直到……）

在「灵感组合」页点击随机，四个维度自动碰撞成一条故事配方；看到顺眼的就点 **+** 收进配方篮，可调可存。

## 不是内容库，是生成器

和常见的「故事素材库」不同，这里的关键词不是成品剧情，而是**经过拆解的、可再组合的最小单元**。371 × 541 × 337 的理论组合空间里，绝大多数从未被写过——工具负责把碰撞结果推到你面前，取舍和落笔永远是你自己的事。

## 数据存在哪里

- 网站本身零后端、零数据库、零追踪，所有页面均为静态文件
- 你的自定义方向、分类、情境、关系、场景、配方，全部存放在**你自己的 GitHub 私有仓库**（通过网页右上角「存储」连接），网站只在你浏览器里运行，任何人（包括项目作者）都看不到你的数据
- 连接用的 fine-grained 令牌仅授权那一个私有仓库的读写，且默认关闭浏览器即失效
